# AWID Livraison

Application de gestion de livraison avec backend Node.js et app mobile Flutter.

## Structure

- `api-v2/` - Backend Node.js/Express
- `mobile/` - Application mobile Flutter
- `.github/workflows/` - CI/CD

## Déploiement

Voir `.env.example` pour la configuration.

## Workflows

- **CI/CD**: Build et déploiement automatique
- **Build APK**: Build automatique de l'APK Android
